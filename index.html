What’s saved

Project names, reviewed capsule versions and handoff copy events stay in this browser’s local storage. They are not uploaded to Solvane. Anyone using this browser profile can access them. Clearing browser data removes your workspace.

Import replaces this browser’s Solvane workspace after confirmation. Export a backup first. The maximum import is 2 MB.

What works here

Create projects, enter context or paste structured update blocks, review individual changes, save versions, restore history, and copy or download a capsule for Claude, ChatGPT, Gemini or Perplexity. Use JSON export and import to move between browsers.

Where the boundary is

GitHub Pages serves static files. This version has no cloud account, cross-device sync, AI extraction, API automation or extension capture. The server app and extension source remain in the repository for the full architecture. Provider accounts are separate and may require sign-in when you open them.

Privacy

This app adds no analytics, cookies, external fonts or third-party scripts. GitHub may receive ordinary hosting request data. Common API key and token formats are redacted before review, but redaction cannot recognize every secret. Review your capsule before sharing it.
