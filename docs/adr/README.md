# Architecture Decision Records

ADRs record decisions that would otherwise become accidental behavior. Update an ADR when a decision changes; do not silently overwrite prior reasoning.

| ADR | Decision | Status |
| --- | --- | --- |
| [001](001-event-log-is-authoritative.md) | Event log is authoritative; snapshots are derived | Accepted |
| [002](002-provider-api-only.md) | Integrate provider APIs, not consumer chat products | Accepted |
| [003](003-handoffs-are-explicit.md) | Handoffs are explicit and user-visible | Accepted |
| [004](004-fallback-is-guarded.md) | Automatic fallback is opt-in and guarded | Accepted |
